Extract PDF tables to JSON for an API or a script. Headers become keys and each row becomes an object. Free, and you review the grid in the browser first.

https://tabulapdf.vercel.app/pdf-to-json

Use JSON when a script, a notebook, or a backend should ingest the table. Use CSV if the consumer is a spreadsheet or a SQL COPY. Both start from the same columns, so fix the grid once.

Empty headers are a bad key. Rename them in the grid before export or the objects will contain blank property names.

This is a file conversion, not a hosted API. You download the JSON. Your PDF is not stored as a dataset.

  1. Load the PDF. Extract the table the same way you would for Excel.
  2. Name the columns. Keys should be short and unique.
  3. Download JSON. Save the file and parse it with your own code.

Questions

Is there an API I can call with a PDF URL?

No public conversion API. You convert in the app and download JSON.

Are numbers typed as numbers?

Cells are extracted as text so leading zeros and mixed currency symbols survive. Cast them in your code after you inspect them.

Can I get XML too?

The app also exports XML from the same grid if your pipeline wants tags instead of objects.
