Combine PDF files into one document, in the order you choose. A free browser tool for packets, exhibits, and reports. No account and no install.

Add the files, drag them into the order a reader should see, and download one PDF. This does not extract tables. If you need the numbers in Excel, convert each file with PDF to Excel first, or merge only after you have the spreadsheets.

Merging is for packets you already have the right to combine. The tool does not unlock a password-protected PDF. Unlock it in the app that created the password, then merge.

Large image-heavy PDFs stay large. Compress after the merge if you need a smaller attachment.

  1. Add two or more PDFs. Open the merge tool and select the files.
  2. Set the order. Cover page first, then exhibits, then the signature page.
  3. Download one PDF. Save the combined file. The originals are not overwritten.

Questions

Does merge pull tables into Excel?

No. Merge only joins pages. Use PDF to Excel on the result, or on each file, if you need a spreadsheet.

Can I merge a scan with a digital PDF?

Yes. Both are just pages. The scan still will not have selectable text until you run AI reading on it.

Is there a file limit?

You are limited by your browser’s memory, not by an account tier. Very large packets may need to be merged in groups.
