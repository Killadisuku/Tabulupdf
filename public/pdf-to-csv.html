Watch commas inside descriptions. The exporter quotes those fields so a vendor name like “Smith, Jones” stays one cell. If a column is still fused to the next one, split it in the grid before you download.

TSV is the better paste into a sheet that is already open. CSV is the better file to keep.

Questions

Is the CSV UTF-8?

Yes. Names and currency symbols keep their characters instead of turning into question marks.

Can I paste into Google Sheets?

Download CSV and import it, or copy TSV and paste. Pasting TSV keeps the columns aligned.

What if the PDF is only a picture of a table?

Use scanned PDF to Excel. That mode sends the page to AI reading. A text-layer PDF does not need it.
